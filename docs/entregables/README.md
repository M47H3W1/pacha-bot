# Entregables NASA Space Apps 2026 (Sangolquí)

- `Presentacion_ES.pdf` y `Presentation_EN.pdf`: presentación de 7 diapositivas (exportada de Canva).
- `Ficha_Proyecto_ES_EN.pdf`: ficha con datos NASA, repositorio y licencia, enlaces y declaración de IA. Fuente LaTeX en `ficha/ficha.tex` (compilar con `pdflatex ficha.tex`).
- `capturas/`: pantallas reales del juego (pacha-chat.vercel.app) con datos NASA POWER, en español e inglés.

Las ilustraciones de Pachita y los cultivos son imágenes generadas con IA y llevan la marca «IA».
