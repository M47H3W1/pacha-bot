# Fotos de cultivos

Pon aquí una foto por cultivo. El bot la usa en "Qué sembrar" y al elegir cultivo.
Si falta una foto, el bot muestra una caja de color con el nombre.

## Nombres de archivo
El nombre debe ser exactamente el código del cultivo, en minúsculas. Sirve `.jpg`, `.jpeg`, `.png` o `.webp`.

## Recomendaciones
- Foto de la planta como la reconoce el agricultor: el fruto o el grano con algo de la planta.
- Fondo simple y buena luz. El bot recorta al centro en cuadrado, así que el cultivo debe estar al medio.
- Tamaño: entre 600 y 1.500 px de lado y menos de 1 MB.
- Usa fotos propias o con licencia libre (por ejemplo Wikimedia Commons, CC BY o CC0) y anota abajo el autor.

## Cómo subirlas
- **Desde GitHub:** en la rama `develop`, entra a esta carpeta, usa *Add file → Upload files* y elige
  *Create a new branch… and start a pull request*. El PR se fusiona solo cuando pasan las pruebas.
- **Desde tu computadora:** copia los archivos aquí, haz commit en una rama `feat/fotos` y abre un PR a `develop`.

Después de fusionar, reinicia el bot para que tome las fotos nuevas.
